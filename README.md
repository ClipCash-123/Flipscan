# FlipScan v0.5

Scan it. Price it. Flip it.

Mobile-first resale decision app with photo upload, smart scanner architecture, profit/ROI/max-buy calculations, BUY/MAYBE/PASS decisions, and local scan history.

For true arbitrary-item recognition and current sold comps, the app calls a secure POST /api/analyze endpoint. It does not invent marketplace sales or expose secret API keys in the browser.
